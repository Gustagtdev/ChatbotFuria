## ChatbotFuria

🐍 FURIA Fan Chat – Versão Front-End (HTML, CSS, JS)
#📌 Visão Geral
**FURIA Fan Chat é um chatbot interativo desenvolvido inteiramente com HTML, CSS e JavaScript puro, sem frameworks ou backend. O objetivo é oferecer uma interface amigável para fãs do time de CS:GO da FURIA interagirem, acompanharem as partidas, receberem curiosidades e se manterem conectados ao universo competitivo da equipe.**
✨ Funcionalidades Implementadas (Front-End)
#💬 Interface de Chat Simulada:
- Comportamento de bot com respostas automáticas pré-programadas.
#📅 Agenda de Jogos (Simulada):    
- Exibe os próximos jogos em formato de mensagem do bot.
#👤 Informações dos Jogadores:
- Mostra lineup atual do FURIA.
#📊 Resultados da última partida:
- Mostra o resultado da última partida.
#🛒Informações sobre a Loja:
- Exibe o link para a loja do furia ao digitar a palavra 'produtos' ou 'loja'.
