🐍 ChatbotFuria
📌 Visão Geral
FURIA Fan Chat é um chatbot interativo desenvolvido inteiramente com HTML, CSS e JavaScript puro, sem frameworks ou backend.
O objetivo é oferecer uma interface amigável para fãs do time de CS:GO da FURIA interagirem, acompanharem as partidas, receberem curiosidades e se manterem conectados ao universo competitivo da equipe.

✨ Funcionalidades Implementadas
💬 Interface de Chat Simulada
- Comportamento de bot com respostas automáticas pré-programadas.

- Interface estilizada que simula uma conversa entre usuário e bot.

📅 Agenda de Jogos (Simulada)
- Exibe os próximos jogos do time em formato de mensagem do bot.

- Acessível através de comandos como /agenda.

👤 Informações dos Jogadores
- Mostra a lineup atual da equipe FURIA.

- Detalhes básicos sobre os jogadores, como nome e função.

📊 Resultados da Última Partida
- Informa o placar mais recente.

- Mostra quem venceu e, se programado, o MVP da partida.

🛒 Loja Oficial da FURIA
- Ao digitar "produtos" ou "loja", o bot envia o link para a loja oficial.

- Ícone de carrinho de compras incluído na resposta.

🧪 Como Usar
- Clone ou baixe este repositório.
- Abra o arquivo index.html em qualquer navegador moderno.
